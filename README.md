# HelpDeskManagement

A basic **Help Desk Management System** built using **C#** and **SQL** to manage and organize support tickets efficiently.

## Features

- Create and manage help desk tickets
- Store customer and issue details
- Track ticket status
- Update and resolve support requests
- Manage ticket-related information through a database
- User-friendly interface for help desk operations

## Tech Stack

- **C#**
- **.NET**
- **SQL**
- **Microsoft SQL Server**
- **Visual Studio**
